Politique de marque de Kodamiko

Le code de Kodamiko est un logiciel libre, sous licence GNU GPL v3 : vous pouvez l’utiliser, l’étudier, le modifier et le partager, comme le dit la licence. Le nom et le logo ne sont pas couverts par cette licence. Ils disent aux utilisateurs qu’une copie de Kodamiko vient de son auteur, telle qu’il l’a publiée, et cette politique veille à ce que ce soit vrai.

La GPL v3 le permet expressément : sa section 7(e) autorise un concédant à ne pas accorder de droits sur ses marques. Cette politique est cette déclaration, et dit ce que vous pouvez faire des marques à la place.

La version anglaise, TRADEMARKS.md, fait foi en cas de différence avec cette traduction.

Les marques

  • Le nom Kodamiko™.
  • Le monogramme K et l’icône de l’application, dans toutes leurs variantes (packaging/brand/).
  • Tout nom ou logo assez proche pour être confondu avec eux (« Kodamico », « Kodamiko Pro », le K recoloré…).

Les marques appartiennent à Eric Ponthiaux.

Ce que vous pouvez faire sans demander

  • Parler de Kodamiko. Dans des articles, critiques, vidéos, conférences, cours, livres et comparatifs, utilisez le nom pour désigner le projet, et le logo pour l’illustrer, tant que personne n’est amené à croire que vous en êtes l’auteur ou que l’auteur vous soutient.
  • Partager les versions officielles, gratuitement. Des copies de Kodamiko telles que publiées, non modifiées, sous leur nom et leur icône : sur un site web, une clé USB, le miroir interne d’une entreprise.
  • L’empaqueter pour une distribution Linux (ou Homebrew, winget, Flathub…) sous son nom, avec les changements que l’empaquetage demande : options de compilation, chemins, bibliothèques de la distribution, correctifs de sécurité. Indiquez dans le paquet en quoi il diffère de la version officielle.
  • Nommer ce qui fonctionne avec lui. Un thème, une recette, un outil ou un tutoriel peut dire pour Kodamiko ou compatible avec Kodamiko : « thème Solarized pour Kodamiko », pas « Kodamiko Solarized ».
  • Réunir des utilisateurs. Un meetup, un forum, un salon de discussion peut utiliser le nom, tant qu’il dit être une communauté, et non le projet lui-même.

Ce qui demande une autorisation écrite

  • Vendre sous le nom. Une copie de Kodamiko, une compilation, un lot, un abonnement, un hébergement, du support ou une formation vendus comme Kodamiko, ou avec son logo. Le code peut être vendu sous la GPL ; ce sont le nom et le logo qui ne peuvent pas servir à cela.
  • Nommer un produit, une entreprise ou un domaine d’après Kodamiko : un éditeur appelé « Kodamiko Studio », une société « Kodamiko Solutions », un domaine kodamiko-pro.com.
  • Les produits dérivés : autocollants, t-shirts, mugs… vendus avec les marques. Pour une distribution gratuite lors d’un événement communautaire, demandez : la réponse sera en général oui.
  • Modifier les marques : d’autres couleurs, formes ou proportions que celles de packaging/brand/, ou le monogramme associé à un autre logo.

Les versions modifiées

Une version qui change ce que fait Kodamiko (nouvelles fonctions, fonctions retirées, autres réglages par défaut, un autre agent intégré) est un fork, ce que la GPL permet. Un fork prend un autre nom et une autre icône :

  • dans le titre de la fenêtre, la fenêtre À propos, l’écran d’accueil ;
  • dans l’exécutable, l’entrée de bureau, l’installeur et le nom du paquet ;
  • sur son site web, ses pages de boutique et ses annonces.

Il peut dire, si c’est vrai, qu’il est basé sur Kodamiko ou un fork de Kodamiko, dans sa description, jamais dans son nom. Les mentions de droit d’auteur et la licence restent, comme l’exige la GPL.

Comment afficher les marques

  • Le nom s’écrit Kodamiko, en un mot, avec un K majuscule.
  • Le logo s’utilise à partir des fichiers de packaging/brand/, sans modification, sur les fonds pour lesquels ils sont faits, avec de l’espace autour.
  • Rien ne suggère un soutien, un partenariat ou un statut officiel qui n’existe pas.

Demander une autorisation

Écrivez à ponthiaux.eric@protonmail.com, ou ouvrez sur le dépôt du projet un ticket intitulé Trademark request, en disant qui vous êtes, ce que vous voulez faire des marques, et où. Une demande qui ne peut pas être publique passe par courriel.

L’autorisation est donnée par écrit, pour un usage précis ; elle peut être retirée si l’usage change.

Cette politique

Elle peut évoluer avec le projet ; la version de la branche main est celle qui s’applique. Dans le doute, demandez : c’est plus rapide que de renommer après coup.
