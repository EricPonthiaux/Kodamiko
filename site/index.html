Free and open source code editor

Built around Claude Code, not added later

Most editors were designed for a human typing code, and AI was added later: a chat panel on the side, or an agent in a terminal that cannot see your editor. Duet starts from the other end: a full code editor built around Claude Code, where Claude sees what you see, and you see everything Claude changes.

Principles

Starting from the other end

In Duet, Claude is not a guest of the editor: the editor was designed for it. Three things follow.

It understands what you are looking at

Claude already knows which file is open, where the cursor is, what is selected and which errors are underlined. Type “fix this” and it knows what you mean: no more pasting code or spelling out file paths.

It acts with the editor's tools

Claude does more than suggest text. It goes to definitions, renames a function everywhere it is used, runs the build and reads the errors, shows a diff, draws a diagram — with the same tools as you. Nothing changes your repository without your approval.

You stay in control

Every change Claude makes appears before your eyes, file by file. A snapshot of the project can be taken before each request, and one click undoes it all. You delegate without risk.

Diagrams

A diagram is worth a thousand lines of terminal

When Claude explains a module, a flow or a refactoring plan, a wall of text scrolling by in a terminal is the hardest way to follow it. In Duet, Claude draws instead, and the diagram becomes a space you share: you both read it, point at it and change it. The conversation goes both ways.

  • You ask, Claude draws“Draw the login flow in src/auth.” Claude reads the code first, then writes the diagram in Mermaid or PlantUML: flowchart, sequence, class, state, data model, C4 or mind map. It opens laid out, ready to read.
  • You point, Claude understandsSelect three boxes and type “merge these into one service”. Claude sees what is selected in the diagram, just as it sees the selection in a file.
  • Claude points, you see“Where is the token checked?” Rather than a paragraph, Claude answers by selecting the right elements in the diagram in front of you.
  • You arrange, Claude keeps itMove the boxes where they make sense to you. When Claude changes the diagram, every element keeps its place, new ones go beside their neighbors, and one Undo cancels its change.
  • From the diagram back to the code“Implement this state machine.” “Does the code still match this diagram?” Once you agree on the picture, it becomes the specification Claude works from.
  • Ready for the docsA diagram is a text file in your repository, reviewed like code, and Claude can export it as SVG or PNG for the documentation.

Agent tools

More than fifty tools in Claude's hands

An agent in a terminal reads and rewrites text. In Duet, Claude works through the editor itself: the language servers, the refactorings, Git, the terminals and the diagrams. The same tools as you, with the same precision.

  • Understand the codeGo to a definition, find every reference, read a symbol's type and documentation, list the errors and warnings, and apply a quick fix.
  • Refactor across the projectRename a symbol or a file, or change a function's signature, through the language server rather than search and replace, and undone in one step.
  • Find its waySearch files, symbols and text across the whole project, and read a file's outline before opening it.
  • Drive GitStatus, history, branches, staging, merge, stash, pull and push; continue or abort a rebase; write the commit message.
  • Build and runRun the project's build and run configurations, type into a terminal and read what it prints, compiler errors included.
  • Show you its workOpen a file at the right line, show a diff, draw and lay out a diagram, and tell you when a long task is done.

Review

Follow every change, review before you commit

Open files reload as Claude edits them, and the Diff view updates after each step. Stage by file, hunk or line, and let Claude write the commit message in the style of your history.

Before committing, a separate, read-only reviewer can go over the staged changes and leave its findings right in the diff.

Editor

A professional editor, without the clutter

Over the years, editors have piled up panels, menus, settings and extensions, until using one became a skill of its own. Duet makes a clean sweep: it keeps what a professional really needs, in a few clear places. And what you would once have hunted for in a menu, you can simply ask Claude.

  • Understand the codeSmart completion, live diagnostics and quick fixes, through language servers and Tree-sitter highlighting.
  • Navigate the projectDefinitions, usages and call hierarchies, an outline, find in files and a command palette.
  • Refactor with confidenceRename, change a signature, move a class — with a preview before applying and a one-step undo, and still fast on very large projects.
  • Git built inLine-level staging, history, branches, merge and rebase, pull, push and stash, without leaving the editor.
  • Commit messages by ClaudeWritten in the style of your team's history, for you to review before committing.
  • Markdown and diagramsA rendered Markdown viewer and a diagram editor for Mermaid and PlantUML.

Get started

Open and cross-platform

Duet is open source (GPL v3) and runs on Linux, Windows and macOS. It is written in C++ to be fast, and it uses your own Claude Code installation without touching your configuration.

# Build and run from source
git clone https://github.com/EricPonthiaux/Duet.git
cd Duet
cmake --preset default
cmake --build --preset default
./build/bin/duet [project-folder]

Requires Qt 6.10+, CMake 3.24+, Ninja and a C++23 compiler (GCC 13+, Clang 17+, Apple Clang 16+ or MSVC 2022). The other dependencies are downloaded and built on the first configuration. See the README for the details.

For developers who want the power of an AI assistant without giving up a serious editor, or control of their code.
